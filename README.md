# vesta-legal

Datenschutzerklärung und Support-Seite für die iOS-App **Vesta**
(App Store: „Vesta Habits & Friends"). Zwei statische Seiten, von GitHub Pages
ausgeliefert, weil der App-Store-Eintrag beide URLs öffentlich erreichbar
verlangt.

| Datei               | Zweck                    | Verwendung in App Store Connect |
| ------------------- | ------------------------ | ------------------------------- |
| `index.html`        | Hilfe und Kontakt        | Support-URL, Marketing-URL      |
| `datenschutz.html`  | Datenschutzerklärung     | Datenschutz-URL                 |

Der Inhalt beschreibt bewusst genau das, was die App tut, nicht mehr: was auf
dem Gerät bleibt, was der Freunde-Feed überträgt und wann eine Kopie stirbt.
Ändert sich am Datenfluss etwas, gehört die Änderung zuerst hierher.
